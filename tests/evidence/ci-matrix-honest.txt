1. CRC-16 Modbus

2. RTU frame — Read Holding Registers
   RTU  slave=0x01 func=0x03 (Read Holding Registers) addr=0x0000 count=10  CRC=0xCDC5 [OK]
   CRC status: OK

3. RTU exception frame — Illegal Data Address
   RTU  slave=0x01 err=0x03 (Read Holding Registers) exc=0x02 (Illegal Data Address)  CRC=0xF1C0 [OK]

4. TCP frame — Write Single Register
   TCP  tid=0x0001  slave=0x01 func=0x06 (Write Single Register) addr=0x0001 value=0x0003

5. JSON output
   {"protocol":"RTU","slave_id":1,"crc":52677,"crc_ok":true,"pdu":{"slave_id":1,"function":3,"function_name":"Read Holding Registers","is_exception":false,"data_len":4,"data":[0,0,0,10]}}

6. Hex string decoder
   "01 03 00 00 00 0A" → 6 bytes: 01 03 00 00 00 0A 

7. Function code lookup
   0x03 → Read Holding Registers
   0x10 → Write Multiple Registers
   0x2B → Encapsulated Interface Transport
   0x06: Write a single analog output register
   0x01 exception: Illegal Function
   0x0B exception: Gateway Target Device Failed to Respond

8. Data section decoder
   Write Single Coil: addr=0x0001, value=0xFF00 (ON)
